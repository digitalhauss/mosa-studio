PANDUAN DEPLOY MOZA STUDIO ADVANCED V11

1. BACKUP
   - Unduh ZIP V10 yang masih berfungsi.
   - Dari Atelier, ekspor proyek aktif lewat Projects -> Export this project.
   - Simpan backup .atelier.json secara pribadi; file bisa berisi media/data privat.

2. UJI STAGING
   - Upload SELURUH isi ZIP V11 ke folder staging website (satu folder).
   - Pastikan index.html dan moza-version-compare.js/.css berada sejajar.
   - Reload tanpa cache setelah upload.

3. CARA PAKAI VERSION COMPARE
   - Masuk Design Editor dan buka proyek.
   - Klik ◇ Compare di toolbar.
   - Klik Pilih backup dan pilih file .atelier.json lama.
   - Baca ringkasan Ditambahkan, Dihapus, Diubah, Dipindahkan.
   - Filter/cari untuk memeriksa perubahan.
   - Ekspor laporan CSV atau JSON jika butuh dokumentasi.
   - Tombol Backup desain aktif memakai ekspor proyek Atelier yang sudah ada.
   - Panel perbandingan TIDAK mengganti desain atau data apapun.

4. CHECKLIST
   [ ] Design Editor dan Preview desktop/mobile terbuka normal.
   [ ] ◇ Compare muncul saat Design Editor aktif.
   [ ] Backup lama valid menghasilkan laporan perbedaan.
   [ ] File rusak ditolak tanpa mengubah proyek.
   [ ] Backup aktif bisa diunduh.
   [ ] Smart Filter V8 + impor V9 + Preflight V10 masih berfungsi.
   [ ] Undo, save, publish dan cloud berjalan di staging.
   [ ] RSVP dan Google Sheets/Supabase dites dengan data percobaan.

5. KEAMANAN / ROLLBACK
   - Jangan taruh file proyek .atelier.json pada folder hosting publik.
   - Jika ada masalah, deploy ulang backup folder V10, bukan file project.
   - Jangan gunakan .atelier.json untuk membandingkan file ZIP atau HTML;
     fitur ini hanya untuk ekspor proyek Atelier berbentuk JSON.

CATATAN: status tes lokal tidak sama dengan verifikasi sistem produksi.
