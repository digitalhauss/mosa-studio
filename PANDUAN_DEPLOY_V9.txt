PANDUAN UPGRADE MOZA STUDIO ADVANCED V8 -> V9

1. Backup file web V8, data project, dan data hosting terlebih dahulu.
2. Extract ZIP V9. Upload SELURUH isinya ke direktori website yang sama.
   Pastikan index.html dan berkas moza-*.js/css berada dalam satu folder.
3. Hard refresh browser (Ctrl+Shift+R) jika file lama masih tersimpan dalam cache.
4. Masuk ke Design Editor, pilih elemen Smart Filter Container di canvas.
5. Scroll panel Properties -> bagian Content Manager (Advanced V9).
6. Untuk backup konten, klik ↓ CSV atau ↓ JSON.
7. Untuk impor, pilih berkas .csv/.json, lihat jumlah dan judul di pratinjau,
   pilih Ganti semua atau Tambahkan, lalu klik Terapkan Impor dan konfirmasi.
8. Cek hasil di Preview desktop dan HP; simpan project seperti biasa.

Batas impor: 1 MB; maksimal 30 item per widget. Upload tidak dikirim ke server.
Smart Filter yang sudah ada tetap berjalan; fitur lama tidak diganti.

Jangan timpa hosting produksi sebelum menguji pada salinan staging.
