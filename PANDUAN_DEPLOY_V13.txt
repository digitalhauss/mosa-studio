PANDUAN DEPLOY MOZA STUDIO ADVANCED V13

A. WEBSITE
1. Backup seluruh folder hosting (V12), file project, serta konfigurasi cloud.
2. Ekstrak ZIP V13. Upload SEMUA file website, bukan index.html saja, dengan struktur tetap.
   Contoh: public_html/index.html, public_html/moza-v13-editor.js, public_html/moza-visual-filter.js,
   public_html/moza-rsvp-manual-v13.js dan file JS/CSS lain di direktori yang sama.
3. Coba dulu di domain staging/subdomain percobaan, bukan langsung mengganti website utama.
4. Hard refresh (Ctrl+Shift+R). Buka editor, lalu coba menu Advanced, Smart Filter, Table,
   FAQ/Tabs, Preview dan ekspor ke PPTX.
5. Buka backup proyek V12, uji edit, save, Undo, Preview dan hasil publish HTML.

B. GOOGLE SHEETS ONLY TANPA SUPABASE
1. Buka spreadsheet tujuan, Extensions -> Apps Script.
2. Tempel seluruh isi file Code.gs (bersihkan script default) ke editor Apps Script.
3. Deploy -> New deployment -> Web app. Execute as: Me, Access: Anyone (bila RSVP publik).
4. Salin URL berakhiran /exec (BUKAN /dev) dari Apps Script.
5. Di Moza, buka editor -> menu Advanced -> RSVP · Google Sheets Manual.
   Pilih Main/Additional RSVP, aktifkan mode manual, masukkan URL /exec dan nama tab, lalu simpan.
6. Untuk Additional RSVP jalankan RSVP Visual Editor -> RSVP Management -> Save & Sync all forms.
7. Export HTML, deploy HTML publik, dan kirim RSVP UJI. Lihat hasil di worksheet; periksa juga
   halaman status di form publik. Jangan menganggap cek akses URL cukup membuktikan kirim data.
8. Bila mode manual TIDAK dipilih, jalur Supabase yang lama tetap berlaku.

C. PENGUJIAN SEBELUM PRODUKSI
- Dua browser (Chrome/Edge), lebar desktop dan mobile, URL internal section/page.
- Login, cloud save, RSVP publik Main+Additional dan dashboard pada order Supabase.
- RSVP Sheets manual; ID request, isi jawaban, mode retry; dan Google Apps Script permission.
- PPTX portrait 9:16 dan landscape 16:9 di PowerPoint dan Canva asli.
- Table 1x1, 1x2, 2x1, dua tabel terpisah, merge/split; visual FAQ/Tabs; animasi idle.
- Rollback ke V12 kalau ada regresi. Jangan menghapus file data hosting atau database.

KETERBATASAN
- Ekspor PPTX mengubah layout web responsif menjadi slide statis. Tidak semua elemen interaktif
  HTML dan animasi web bisa direpresentasikan sebagai bentuk editable di PPTX.
- Script Apps Script publik menerima request dari internet dan berpotensi menerima spam.
  Perhatikan kuota Google dan monitoring spreadsheet. Keamanan dan throttling perlu diaudit
  sesuai trafik nyata sebelum penggunaan luas.
- ZIP menyertakan Code.gs sebagai sumber manual, bukan file yang otomatis dijalankan hosting.
