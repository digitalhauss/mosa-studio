MOZA STUDIO ADVANCED V11 — VERSION COMPARE
6 November 2026

DASAR
Moza Studio Advanced V10 Upgrade (termasuk fitur V6–V10).

FITUR BARU
1. Toolbar Design Editor: tombol ◇ Compare.
2. Buka file .atelier.json/.json hasil ekspor proyek Atelier lama.
3. Perbandingan read-only dengan proyek yang sedang terbuka:
   - halaman, section, dan elemen yang ditambahkan atau dihapus;
   - properti elemen/section/halaman yang berubah (nama properti, bukan nilai);
   - elemen/section/halaman yang pindah parent atau berubah urutan.
4. Perubahan urutan akibat sisipan/penghapusan item lain tidak salah ditandai
   sebagai pemindahan.
5. Ringkasan jumlah halaman/section/elemen sebelum dan sesudah.
6. Filter jenis perubahan dan pencarian nama/lokasi/properti.
7. Ekspor laporan perbandingan CSV atau JSON (hanya aksi eksplisit).
8. Tombol Backup desain aktif memakai fitur ekspor JSON bawaan Atelier;
   V11 tidak membuat sistem backup data terpisah.
9. Peringatan untuk ID hilang/duplikat, validasi struktur backup, batas 80 MB
   untuk file serta perlindungan perbandingan pada struktur terlalu besar.
10. Dialog dapat digunakan via keyboard; close Escape; data backup referensi
    sementara dibersihkan saat dialog ditutup.

BATASAN PENTING
- Snapshot dibandingkan berdasarkan ID. ID yang hilang atau ganda
  dapat membuat hasil perbandingan kurang akurat.
- Data media biner, validitas URL, respons RSVP dan sinkronisasi cloud
  tidak diperiksa. Gambar bisa berubah isinya meskipun ID tidak berubah.
- Version Compare BUKAN restorasi; untuk memulihkan gunakan proses impor
  bawaan setelah backup dan pengujian di lingkungan yang aman.
- File .atelier.json dapat berisi media dan informasi privat. Jangan
  unggah backup editable ke hosting publik atau membagikannya sembarangan.
- Belum ada pengujian server/hosting nyata dan pengiriman RSVP live.

PENGUJIAN

  perubahan urutan key, struktur rusak, CSV injection, duplikat ID).

  pencarian, ekspor CSV, backup bawaan, Escape, tombol toolbar.
- Node --check pada semua file JS addon; pemeriksaan keberadaan aset,
  struktur ZIP dan perbandingan ke V10.
- Chromium tidak dapat mengakses file:// atau localhost dalam lingkungan
