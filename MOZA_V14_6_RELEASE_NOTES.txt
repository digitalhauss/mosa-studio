MOZA STUDIO ADVANCED V14.6
Direct Canvas Table Editor + Advanced Menu Dismissal

WHAT CHANGED
1. Table cells are now rendered as native editable HTML cells on the design canvas. Click a cell and type directly in place.
2. Table editing no longer opens the separate Table Editor modal from the normal table creation or Properties workflow.
3. Cell formatting is available in the existing Properties sidebar: font, size, text color, cell background, horizontal alignment, vertical alignment, padding, border color/width, bold, italic and underline.
4. Cell formatting applies only to the selected cell or selected range.
5. Merge and Split operate on a range selected directly on the canvas. Use Properties > Pilih rentang sel, tap the first cell, then tap the last cell.
6. Merge preserves the values in covered cells. Split restores those values.
7. Row and column insert/delete actions are available in Properties and retain cell styles and compatible merge geometry.
8. Table-wide appearance controls remain available in a collapsible Properties section.
9. The Advanced overflow menu closes when the user taps outside it, presses Escape, scrolls, or resizes the viewport.
10. Published/Preview output continues to use the existing isolated table HTML renderer. Direct contenteditable editing is limited to the design canvas.

DEPLOYMENT
Replace index.html and upload moza-v14.6-canvas-table-editor.js to the same repository root.
Keep moza-v14.5-table-editor.js and every existing CSS/JS asset. Do not rename the new script.

COMPATIBILITY
Existing tableData, merges, cellStyles and V14.5 serialization are retained. Existing table contents are not intentionally cleared during merge.
