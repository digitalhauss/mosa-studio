PANDUAN DEPLOY MOZA STUDIO ADVANCED V8

1. Backup file situs saat ini (V7) dan export/backup data proyek pengguna.
2. Ekstrak seluruh isi ZIP V8, jangan upload ZIP sebagai file HTML.
3. Upload seluruh index.html dan moza-*.js/css ke direktori situs yang sama.
   Biarkan struktur dan konfigurasi server/cloud yang sudah ada.
4. Refresh paksa browser (Ctrl+Shift+R), buka salinan project.
5. Uji buka Editor, Preview Desktop/Tablet/HP, simpan dan muat ulang.
6. Untuk Smart Filter baru: tambahkan widget, buka Properties, centang
   Aktifkan pagination, pilih item per halaman; centang hitungan kategori
   bila dibutuhkan. Coba search, kategori, sorting dan tombol next/prev.
7. Untuk Smart Filter lama: pilih widget > Update HTML Widget jika ingin
   fitur V8. Perubahan manual embed HTML widget bisa tertimpa; backup dulu.
8. Klik ✦ Audit > Periksa ulang > ↓ Ekspor Audit JSON. Data tetap lokal.
9. Uji native Undo/Redo dan seluruh alur lama yang bergantung pada server,
   terutama RSVP, Supabase, Google Sheets, publish, dan login.
10. Bila ada masalah pada data proyek, kembalikan file dan backup V7;
    jangan gunakan tombol repair tanpa meninjau isu yang terdeteksi.

Catatan: halaman website adalah index.html, seluruh moza-*.js/.css wajib
berada di folder yang sama. Tidak ada database/SQL baru untuk V8.
