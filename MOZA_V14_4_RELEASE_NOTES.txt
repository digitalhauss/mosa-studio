2. TABLE EDITOR

The table editor now uses an editor-and-preview layout. On wide screens, controls and the live preview appear side by side. On narrow screens, they stack vertically.

Added table operations:
- Select a cell by row and column number.
- Insert or delete a row or column relative to the selected cell.
- Move a row up or down.
- Merge a rectangular selection of cells.
- Split a merged cell.
- Set equal column widths or fit columns to content.

Added appearance settings:
- Font family.
- Border style: solid, dashed, dotted, double, or none.
- Vertical alignment.
- Minimum row height.
- Header text colour.

The existing header toggle, header background, cell background, text colour, border colour, font size, cell padding, border width, and text alignment remain available. The preview updates as the user edits cell content or appearance settings.

Merge behaviour: non-empty cell contents are combined in the top-left cell with a slash separator. Splitting restores the cell grid and keeps the combined text in the top-left cell; other cells remain blank.

3. BUG FIXES

- Replaced the invalid table preview lookup with the actual __mz13TableBridge adapter.
- Connected the table preview to the table renderer and document builder, so the same merged-cell HTML is used in preview and saved embed output.
- Removed the whole-body MutationObserver from the visual editor add-on. The table bridge now handles modal rendering directly, avoiding repeated preview-triggered mutation callbacks.
- Added the missing table input listener. Cell edits now update the preview before the field loses focus.
- Corrected photo preset IDs so selecting a preset applies the intended filter.
- Corrected text effect mappings for Neon, Outline, Glitch, and Emboss.
- Made the gradient-angle control update the existing text gradient/shimmer model.
- Grouped visual-effect undo snapshots around control focus rather than creating a history snapshot for every slider tick.
- Removed redundant history commits from table draft-only operations. The table is committed when the user applies it.
- Preserved saved merges when switching between different tables. Structural changes within the current table clear merges to avoid invalid cell spans.
- Kept selection coordinates aligned after row and column operations.
- Added guarded initial refresh so saved V14.4 visual effects render after the editor finishes loading.
