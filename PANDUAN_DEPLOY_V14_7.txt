MOZA V14.6.1 REPACK -> V14.7 UPGRADE (NO MASS DELETION)

BEFORE YOU UPGRADE: BACK UP THE V14.6.1 WEBSITE AND YOUR PROJECTS.

REPLACE exactly these existing website files:
  index.html
  moza-visual-filter.js
ADD this new website file in the SAME folder as index.html:
  moza-cross-project.js

Leave all other .js, .css, RSVP, and cloud settings untouched.
Do not upload Code.gs to GitHub Pages; that belongs in Google Apps Script.
Upload to GitHub and commit. Wait for Pages deployment, then hard refresh.

HOW TO LINK PROJECTS
- Keep both projects saved locally in Moza Studio in the same browser.
- Select an element or navigation item > Properties > Link to.
- Choose Another Project, then choose its destination project name.
- For Smart Filter cards, use Link type > Another Project.
- For Floating Assets, use Jenis link > Another Project.

HOW TO EXPORT MULTIPLE PROJECTS
- Open the main project.
- Go to Download HTML / ZIP > Combined Website ZIP.
- Tick every project to publish together; linked projects are checked by default.
- Click Download Combined Website ZIP.
- Extract the new ZIP and upload all files/folders to ONE site directory.
- Keep index.html and projects/... folders as generated.
- Do not upload the editor/source ZIP to the public published website.

EXAMPLE DEPLOY STRUCTURE
  index.html
  .nojekyll
  assets/media-0001.jpg
  projects/project-b/index.html
  projects/project-b/assets/media-0001.jpg
  README_DEPLOY.txt

Cross-project navigation uses relative addresses, so these links work when
hosted on a subpath (e.g., a GitHub Pages repository) as well as the domain root.

IMPORTANT: A combined deploy is not a merge of editable documents; each
published project remains independent. The destination project must have been
saved in the current local project library to be included. Cloud-only projects
must be opened/saved locally before export.
