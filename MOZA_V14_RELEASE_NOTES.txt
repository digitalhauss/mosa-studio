MOZA STUDIO ADVANCED V14 — RELEASE CANDIDATE
============================================
Based on Moza Studio Advanced V13. The core editor, RSVP/Supabase,
Google Sheets Apps Script, project schema, and existing asset system remain in place.

WHAT'S NEW
- Continuous Rotate (linear 360° with no stop at each revolution), reverse rotation,
  Orbit, Drift, Float Diagonal, Breathing, Pendulum, Rock, Wave, Shimmer,
  Hue Cycle, and 3D Flip among Always Moving effects.
- Additional Appear effects: Blur Up, Soft Fade, Zoom & Rotate, Drop In,
  Elastic Reveal, Diagonal Slide, 3D Flip Up, and Reveal Up.
- Visual Smart Filter supports 10 template styles and ready-to-edit sample cards:
  Wedding Catalog, Portfolio, Photo Gallery, Services & Pricing, Editorial
  Lookbook, Event Schedule, Product Collection, Elegant, Minimal, Classic.
- Each card has an Upload image action and a selector for existing Uploads assets.
  Images use Atelier's existing preview/confirmation and persistence pipeline.
- Card button text is always rendered when non-empty, even if a destination URL,
  page or section has not yet been configured. Until then, it is not clickable.
- English default public labels, editable result-count template ({count}),
  search placeholder, sort labels, empty state and pagination labels.
- Responsive card columns can be configured independently for Desktop,
  Tablet, and Mobile, with additional narrow-screen layout safeguards.
- Accordion/Sliding Tabs have editable labels and honor configured type sizes
  on mobile instead of forcing fixed 14px text.
- Optional Responsive Audit and Fit Selected controls for Tablet/Mobile
  geometry, with Undo support. Existing Desktop geometry is not overwritten.
